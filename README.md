# Event Horizon — archived predecessor

Active development has moved to **[Epsilon Reticuli B](https://github.com/TheArchitect71/epsilon-reticuli-b)**, the combined Epsilon/Event Horizon people workspace and frontend for **[Betazed MongoDB](https://github.com/TheArchitect71/betazed-mongodb)**.

Epsilon contains the cohesive navigation, profile editor, directory views, registration/login, and MongoDB-backed CRUD. Follow its README to run the frontend and backend together.

This repository is archived to preserve Event Horizon’s original code, commits, and the earlier browser-local combined demo. Its Git history remains separate from Epsilon’s history. Existing browser-local data is not automatically uploaded to the API.
